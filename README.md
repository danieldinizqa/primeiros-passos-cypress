#  Primeiros Passos - Cypress (SauceDemo)

Este repositório é dedicado aos meus primeiros exercícios de automação utilizando o framework **Cypress**.

##  Objetivo
O foco principal foi aprender a estrutura básica do Cypress, seletores de elementos e asserções simples.

##  Testes Inclusos
- **Login SauceDemo** (`saucedemo.cy.js`):
  - Validação de login com credenciais válidas.
  - Validação de mensagem de erro para usuário bloqueado.

##  Como Rodar
1. Instale as dependências: `npm install`
2. Execute o Cypress: `npx cypress open`
